# Visual Guideline — CMH Logistics

> ถอดจาก `moodboard.png` (v1 · Grid/Bento · Navy + Amber) ที่อนุมัติแล้ว
> **หน้าเพจต้องยึดไฟล์นี้** — ห้ามคิดสี/ฟอนต์ใหม่เอง (กฎข้อ 8 ของโปรเจกต์)

## Mood

**มั่นคง · เป็นระบบ · ถูกต้อง · มืออาชีพ · ตรวจสอบได้**

- **Tone label: `Industrial`** (จาก 11 ทิศทางใน `design-standards.md`)
  เพราะลูกค้าเป็นโรงงาน/ผู้นำเข้า B2B ที่ตัดสินใจด้วย "ความน่าเชื่อถือ" ไม่ใช่ความสวย —
  หน้าเพจต้องดูเหมือนเครื่องมือทำงานที่แม่นยำ ไม่ใช่โบรชัวร์ประดิษฐ์
- **Theme: Dark** — moodboard เป็นพื้นกรมท่าเข้มทั้งใบ ทำให้ภาพตู้คอนเทนเนอร์สีสด
  และ CTA สีส้มเด้งออกมาได้เต็มที่ · พื้นเข้มยังสื่อ "จริงจัง มั่นคง" ตรงกับ B2B โลจิสติกส์

## Palette

| บทบาท | HEX | ใช้ตรงไหน |
|---|---|---|
| `--bg` background | `#08192A` | พื้นหลังหลักทั้งหน้า (กรมท่าเข้มเกือบดำ) |
| `--surface` การ์ด/ฟอร์ม | `#0D2338` | กล่องฟอร์ม การ์ดบริการ panel |
| `--surface-tint` | `#0F2C47` | แถบสลับ section, hover ของการ์ด |
| `--line` เส้นขอบ | `#1D3B58` | border การ์ด · เส้นคั่น section |
| `--steel` secondary | `#2F6F9F` | ลิงก์ · ไอคอน · bullet · กราฟ |
| `--accent` **CTA** | `#E8730C` | **ปุ่มหลักเท่านั้น** — contrast สูงสุดในหน้า |
| `--accent-2` | `#F5A13A` | eyebrow · label · hover ของ accent |
| `--ink` ตัวอักษรหลัก | `#EAF1F8` | หัวข้อ + เนื้อความบนพื้นเข้ม |
| `--ink-muted` | `#9DB2C7` | คำอธิบาย · caption · placeholder |
| `--surface-light` | `#F2F5F8` | เฉพาะ section สว่างสลับ (ถ้าต้องใช้) — ink กลับเป็น `#0B1622` |

**คู่สีที่เป็นลายเซ็นแบรนด์: กรมท่าเข้ม `#08192A` + ส้มเครน `#E8730C`**
ส้มนี้ถอดมาจากสีเครนยกตู้ในภาพจริง ไม่ใช่ส้มที่คิดขึ้นลอยๆ — ใช้อย่างประหยัด
(CTA + eyebrow + เส้น accent สั้นๆ เท่านั้น) ถ้าใช้เยอะจะเสียความ "มั่นคง"

## Typography

| บทบาท | ฟอนต์ | น้ำหนัก | หมายเหตุ |
|---|---|---|---|
| Headline | **Bai Jamjuree** | 600–700 | รองรับไทย มีคาแรกเตอร์ ทรงเหลี่ยมกึ่งเทคนิค เข้ากับ industrial |
| Body | **IBM Plex Sans Thai** | 300–400 | อ่านยาวสบาย โทนวิศวกรรม ไม่หวาน |
| Label / ตัวเลข | **Bai Jamjuree** | 600 | uppercase + `letter-spacing: .18em` สำหรับ eyebrow/แท็ก |

- ห้ามใช้ Inter / Roboto / Arial / Helvetica / system-ui / **Sarabun** เป็นฟอนต์หลัก
- ตัวเลข (จำนวนตู้ ปี ราคา) ใช้ `font-variant-numeric: tabular-nums`
- หัวข้อใหญ่ `text-wrap: balance` · เนื้อความกว้างไม่เกิน ~65 ตัวอักษร

## Photography direction

- **ประเภทภาพ**: ท่าเรือ · ลานตู้คอนเทนเนอร์ · เครนยกตู้ · เรือขนส่ง · รถบรรทุก · คลังสินค้า
- **มุมกล้อง**: มุมสูง (aerial/top-down) เป็นลายเซ็น — เห็น "ระบบ ระเบียบ ตรวจสอบได้"
  ภาพ hero และภาพทีมงานใน moodboard ใช้มุมสูงเหมือนกัน ทำให้ทั้งใบเป็นภาษาเดียวกัน
- **คน**: ถ้ามีคน ต้องเป็นคน **กำลังทำงานจริง** (ก้มดูเอกสาร ชี้แผนผัง ดูหน้าจอ)
  ไม่ใช่ยิ้มใส่กล้อง · เห็นได้ทั้งชายหญิง อายุ 30–50 แต่งกายทำงานจริง
- **แสง**: แสงธรรมชาติกลางวัน หรือแสงเย็น/ฟ้าครึ้ม · ไม่ใช้แสงสตูดิโอนุ่มๆ แบบโฆษณา
- **การปรับสี**: ทับ tint กรมท่า `rgba(15,44,71,.30)` + gradient เข้มจากล่างขึ้น
  เพื่อให้ตัวหนังสือขาวอ่านออกและภาพทุกใบเป็นโทนเดียวกัน

### ลักษณะรูปที่ห้ามใช้ (สำคัญที่สุดตอนหาภาพ)

- ❌ คนยิ้มใส่กล้องแบบ stock photo / จับมือกันหน้าตึกกระจก
- ❌ เรือสำราญ · รีสอร์ต · ภาพท่องเที่ยว (เคยหลุดมารอบแรก ต้องคัดออก)
- ❌ กราฟิก 3D เรนเดอร์ · ไอคอนธุรกิจ clip-art · ลูกโลกมีเส้นเชื่อม
- ❌ ภาพที่ดูออกว่า AI generate (นิ้วเกิน ตัวหนังสือมั่ว ตู้ลอย)
- ❌ โลโก้สายเรือจริงเด่นจนดูเหมือนอ้างว่าเป็นพาร์ตเนอร์
- ❌ ภาพสีหวาน/พาสเทล/ฟิลเตอร์อุ่นจัด — ขัดกับ palette กรมท่า

## UI

- **Radius: 6px** (การ์ด/ปุ่ม/ฟอร์ม) — จาก moodboard ที่ใช้มุมคมเกือบเหลี่ยม
  ห้าม `rounded-2xl`/มุมมนใหญ่ ซึ่งทำให้ดูเป็นแอปคอนซูเมอร์ ไม่ใช่ B2B
- **Shadow**: แทบไม่ใช้ — แยกชั้นด้วย **สีพื้น + เส้นขอบ `1px solid #1D3B58`** แทน
  (moodboard แยกช่องด้วยเส้นและระยะห่าง ไม่ใช่เงา)
- **Spacing rhythm**: 8px grid · ช่องไฟระหว่างช่อง 14px · padding section 56px (มือถือ 24px)
- **Section divider**: เส้น 3px ที่เป็น ส้ม 18% แรก แล้วต่อด้วยสีเส้นกรมท่า
  (ลายเซ็นจาก moodboard — ใช้ซ้ำเป็นตัวคั่นหัวข้อได้)
- **Texture**: noise/grain บางๆ 2–3% บนพื้นเข้ม เพื่อไม่ให้แบน · ห้าม glass morphism
- **Layout**: bento grid — ช่องขนาดไม่เท่ากันแต่ชิดกริดเดียวกัน ใช้กับ section บริการและตัวเลข proof
- **ปุ่ม**: พื้น `#E8730C` ตัวหนังสือ `#1A0D00` หนา 600 · hover เข้มขึ้น ~12% (`#D0670A`)
  · focus ring 2px `#F5A13A` · disabled opacity 45%

## ข้อไหนถอดจากภาพ / ข้อไหนเป็นการอนุมาน

| หัวข้อ | ที่มา |
|---|---|
| Palette ทุกค่า HEX | **ถอดจากภาพจริง** — เป็นค่าที่ใช้วาด moodboard และตรงกับสีเครน/ตู้ในรูป |
| Typography (Bai Jamjuree / IBM Plex Sans Thai) | **ถอดจากภาพจริง** — เป็นฟอนต์ที่เรนเดอร์อยู่ใน moodboard |
| Photography direction + รูปที่ห้ามใช้ | **ถอดจากภาพจริง** + บทเรียนตอนคัดรูป (รูปรีสอร์ตหลุดมาแล้วถูกเปลี่ยนออก) |
| Radius 6px · เส้นขอบแทนเงา · divider ส้ม | **ถอดจากภาพจริง** |
| **สไตล์ปุ่ม (hover/focus/disabled)** | ⚠️ **อนุมาน** — ใน moodboard ไม่มีปุ่มจริง ยึดจากสี accent + กฎ contrast |
| **Spacing 8px grid** | ⚠️ **อนุมาน** — จากระยะห่างที่ใช้จริงใน moodboard แล้วปัดเป็นระบบ |
| **Texture noise 2–3%** | ⚠️ **อนุมาน** — moodboard เป็นพื้นเรียบ แต่ `design-standards.md` กำหนดให้มี depth |
