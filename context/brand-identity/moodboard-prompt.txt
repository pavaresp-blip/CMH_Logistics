วิธี regenerate
---------------
1. ดาวน์โหลดรูปตาม Pixabay ID ด้านล่างลงใน ./img/[slot].jpg
2. เปิด moodboard.html (อยู่โฟลเดอร์เดียวกัน) ที่อ้าง ./img/*.jpg
3. ถ่ายด้วย Playwright:
   NODE_PATH=$(npm root -g) node -e '
   const {chromium}=require("playwright");
   (async()=>{const b=await chromium.launch();
    const p=await b.newPage({viewport:{width:1080,height:1920}});
    await p.goto("file://"+process.cwd()+"/moodboard.html",{waitUntil:"networkidle"});
    await p.waitForTimeout(1500); await p.screenshot({path:"moodboard.png"}); await b.close();})();'
