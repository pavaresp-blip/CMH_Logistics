# Clients (ลูกค้าของเรา)

> ไฟล์นี้กำหนดว่า copy จะพูดกับใคร ด้วยภาษาแบบไหน และต้องแก้ข้อกังวลอะไร

## ลูกค้าหลัก (ICP)
- อายุ: 30–55 ปี (เจ้าของกิจการ / ฝ่ายจัดซื้อ / ฝ่ายนำเข้า)
- อาชีพ / ไลฟ์สไตล์: เจ้าของโรงงาน · ผู้นำเข้า/ผู้ค้าส่ง · SME ที่สั่งของจากจีนประจำ ·
  ฝ่ายจัดซื้อ/บัญชีของบริษัทที่ต้องการเอกสารครบ
- รายได้ประมาณ: ธุรกิจมียอดสั่งซื้อจากจีนตั้งแต่หลักแสน–หลักล้านบาท/เดือน
- อยู่แถวไหน: ทั่วประเทศไทย เน้นเขตอุตสาหกรรม กรุงเทพฯ–ปริมณฑล–ชลบุรี/EEC

## เขาอยากได้อะไรจริงๆ (ไม่ใช่แค่ตัวสินค้า — คือผลลัพธ์ในชีวิต)
- นำเข้าของจากจีนได้ **ถูกต้องตามกฎหมาย** สบายใจ ไม่ต้องกลัวโดนจับ/ของโดนยึด
- ได้ **ใบขนสินค้า + เอกสารครบในนามบริษัทตัวเอง** เอาไปใช้ VAT / เครดิตภาษี / ทำบัญชีได้เต็ม
- ธุรกิจ **โตแบบมีระบบ** ตรวจสอบได้ ทำงานกับธนาคาร/นักบัญชี/สรรพากรได้ราบรื่น
- มีคนดูแลให้ครบตั้งแต่ต้นทางจีนถึงหน้าโรงงาน ไม่ต้องวิ่งเองหลายเจ้า

## Pain / สิ่งที่ทำให้เขาหงุดหงิดอยู่ทุกวันนี้
- เคยใช้ "ฝากขน / เหมาเคลียร์" (นำเข้าใต้หัวคนอื่น) → ได้ของแต่ **ไม่มีเอกสารในนามตัวเอง** ใช้ภาษีไม่ได้
- กลัวความเสี่ยงทางกฎหมาย — สำแดงไม่ตรง เสียภาษีไม่ครบ ของอาจโดนยึด/เสียค่าปรับย้อนหลัง
- ราคาถูกตอนแรก แต่ **โตแล้วไปต่อไม่ได้** เพราะบัญชี/ภาษีไม่ตรง ขอสินเชื่อ/ทำงบไม่ได้
- เจอ freight เจ้าที่ตอบช้า เอกสารผิด ประสานงานจีน–ไทยไม่ต่อเนื่อง ของค้างท่า

## Objections — เหตุผลที่เขาลังเลไม่ซื้อ + เราตอบว่าอะไร
| ข้อลังเล | เราตอบว่า |
|---|---|
| "นำเข้าถูกต้องแพงกว่าฝากขนเยอะไหม" | ต้นทุนที่จ่ายกลับมาเป็นภาษีที่ใช้ได้เต็ม + ลดความเสี่ยงค่าปรับย้อนหลัง คุ้มกว่าในระยะยาว |
| "ยุ่งยาก เอกสารเยอะ ทำเองไม่เป็น" | ทีมงานมืออาชีพจัดการพิธีการ/เอกสาร/ภาษีให้ครบ ลูกค้าแค่เตรียมข้อมูลสินค้า |
| "ของน้อย ไม่เต็มตู้ ทำได้ไหม" | ได้ทั้งเต็มตู้ (FCL) และรวมตู้ (LCL) — ของน้อยก็นำเข้าถูกต้องได้ ไม่ต้องรอเต็มตู้ |
| "เชื่อถือได้แค่ไหน เพิ่งเคยได้ยินชื่อ" | อยู่ในเครือ Supersunway Cargo ก่อตั้งปี 2020 นำเข้า 20+ ตู้/เดือน มีเคสจริง |
| "ต้องมีบริษัท/หัวนำเข้าก่อนไหม" | เราแนะนำและช่วยให้ลูกค้านำเข้าในนามหัวของตัวเองได้ ใช้สิทธิ์ภาษีได้เต็ม |

## เขาเปรียบเทียบเรากับอะไร (คู่แข่ง / ทางเลือกอื่น รวมถึง "ไม่ทำอะไรเลย")
- บริการ "ฝากขน / เหมาเคลียร์" ราคาถูก (แต่ไม่มีเอกสารในนามตัวเอง)
- shipping/freight forwarder เจ้าอื่นที่นำเข้าถูกต้องเหมือนกัน
- จ้าง broker + จัดการเองแยกส่วน (ยุ่ง ประสานหลายเจ้า)
- "ทำแบบเดิมไปก่อน" — ใช้ฝากขนต่อ ทั้งที่รู้ว่าโตแล้วมีปัญหา

## Trigger — อะไรทำให้เขาตัดสินใจ "เอาวะ ลองเลย" วันนี้
- ธุรกิจโตจนบัญชี/สรรพากรเริ่มมีปัญหา ต้องการเอกสารให้ถูกต้อง
- โดนตรวจ/โดนปรับ หรือได้ยินข่าวคนอื่นโดน เลยอยากทำให้ถูก
- มีล็อตใหม่กำลังจะสั่ง อยากได้ใบเสนอราคาเทียบก่อนตัดสินใจ
- อยากขอคืน VAT / ทำงบให้สวยเพื่อขอสินเชื่อขยายกิจการ
