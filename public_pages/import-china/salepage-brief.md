# Salepage Brief — import-china

## หน้านี้ขายอะไร

- **สินค้า/บริการที่หน้านี้ขาย**: บริการนำเข้าสินค้าจากจีนมาไทยแบบถูกต้องตามกฎหมาย
  (เต็มตู้ FCL · รวมตู้ LCL · พิธีการศุลกากร+เอกสาร · door-to-door)
- **sku ที่จะแสดงบนหน้า**: `CMH-FCL-QUOTE` · `CMH-LCL-QUOTE` · `CMH-CONSULT` (ครบทั้ง 3 ตัวใน catalog)
- **hero offer ของหน้านี้**: **`CMH-FCL-QUOTE`** — ขอใบเสนอราคานำเข้าเต็มตู้ (CTA หลักทุกปุ่มชี้มาที่นี่)

|---|---|---|
| ขายตัวเดียว | ☐ | |

> ⚠️ **ไม่มีขั้นชำระเงินบนหน้านี้** — freight คิดราคา quote รายเคส (ตามน้ำหนัก/ปริมาตร/เส้นทาง)
> ปุ่มทุกปุ่มจึงจบที่ **ฟอร์มขอใบเสนอราคา** ไม่ใช่ Stripe checkout · `stripePriceId` ใน catalog เป็น `null`

## เป้าหมายของหน้า

- **เป้าหมายหลัก**: **เก็บ lead** → ทีมติดต่อกลับเพื่อออกใบเสนอราคา → ปิดเป็นเคสนำเข้า
- **วัดผลยังไงว่าหน้านี้สำเร็จ**: จำนวน lead ที่เข้าสเตจ "ขอใบเสนอราคาจากหน้าเพจ" ใน HubSpot
  และสัดส่วนที่เดินต่อไปสเตจ "ส่งใบเสนอราคาแล้ว"

## ใครคือคนอ่านหน้านี้

- **กลุ่มเป้าหมายเฉพาะของหน้านี้**: เจ้าของโรงงาน / ผู้นำเข้า / ฝ่ายจัดซื้อ ที่สั่งของจากจีนอยู่แล้ว
  และกำลังใช้ (หรือเคยใช้) บริการฝากขน/เหมาเคลียร์ แล้วเริ่มมีปัญหาเรื่องเอกสาร–ภาษี
- **เขามาจากไหน**: **หลายทางปนกัน** (FB/IG ad · LINE · bio link · Google)
  → **เขียนให้คนที่ยังไม่รู้จัก CMH อ่านรู้เรื่อง** อธิบายตั้งแต่ต้นว่าเราคือใครและต่างจากฝากขนยังไง
  ห้ามสมมติว่าผู้อ่านรู้จักแบรนด์มาก่อน
- **เขารู้อะไรมาก่อนแล้วบ้าง (awareness)**: **Problem-aware** — รู้ว่าตัวเองมีปัญหาเรื่องเอกสาร/ภาษี
  แต่ยังไม่รู้ว่ามีทางออกที่ทำได้จริงและไม่แพงอย่างที่กลัว

## มุมที่จะนำเสนอ (angle)

- **angle ของหน้านี้**: **"ใช้ภาษีที่เสียไปได้เต็มจำนวน"**
  — นำเข้าในนามหัวบริษัทของคุณเอง ได้ใบขนสินค้าครบ เอาไปใช้ VAT / เครดิตภาษี / ทำบัญชีได้จริง
- **ทำไมเลือก angle นี้**: เป็น pain ที่ "เจ็บเป็นตัวเงิน" ที่สุดของลูกค้าโรงงาน — ฝากขนถูกกว่าตอนจ่าย
  แต่ภาษีที่เสียไปใช้ไม่ได้เลยเพราะของเข้ามาในนามคนอื่น พอโตแล้วทำบัญชี/ขอสินเชื่อไม่ได้
  angle นี้เปลี่ยนบทสนทนาจาก "ค่าขนส่งเท่าไหร่" (แข่งราคา) เป็น "คุ้มกว่ายังไง" (แข่งคุณค่า)
- **หน้าอื่นในรีโปใช้ angle อะไรอยู่**: ยังไม่มีหน้าอื่น — หน้านี้เป็นหน้าแรก

## ข้อจำกัด / สิ่งที่ห้ามพูด

- **ห้ามเคลม**:
  - ห้ามใส่ testimonial / รีวิว / ชื่อลูกค้า เพราะ**ยังไม่มีของจริง** (ห้ามแต่งขึ้น)
  - ห้ามเคลม "ถูกที่สุดในไทย" / "รับประกันผ่านชัวร์ 100%" — พิสูจน์ไม่ได้
  - ห้ามพูดอะไรที่สื่อว่าช่วยเลี่ยงภาษี/ทำสีเทา — ขัดกับจุดยืนแบรนด์โดยตรง
  - ห้ามอ้างว่าเป็นพาร์ตเนอร์กับสายเรือ/หน่วยงานใด ถ้าไม่มีจริง
- **โปรโมชั่นที่มีจริงและวันหมดอายุ**: **ไม่มี**
  → **ห้ามใส่ countdown / "เหลืออีก N ที่" / urgency ปลอมทุกชนิด**
  urgency ที่ใช้ได้มีทางเดียวคือของจริง: ตารางเรือและค่าระวางเปลี่ยนตามรอบ ยิ่งขอราคาเร็วยิ่งล็อกได้เร็ว
- **ข้อกฎหมาย/ข้อบังคับ**: สินค้าบางประเภทต้องมีใบอนุญาต (มอก./อย.) — ต้องพูดตามจริงว่า
  "ตรวจให้ก่อนว่าสินค้าของคุณต้องขออะไรบ้าง" ไม่ใช่รับปากว่าผ่านได้ทุกกรณี
