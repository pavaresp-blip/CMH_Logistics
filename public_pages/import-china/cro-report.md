## Top 5 ที่ดีอยู่แล้ว

1. **Angle "ใช้ภาษีได้เต็ม" เดินทั้งหน้า** — H1 → §3 ปัญหา → §7 ตารางเทียบ → FAQ ข้อ 1 ไม่หลุดไปเป็นการแข่งราคาขนส่ง
2. **ฟอร์มอยู่เหนือ fold** ทั้ง desktop และ mobile — ไม่ต้องเลื่อนหาปุ่ม
3. **ตารางเทียบ ฝากขน vs CMH** เป็นชิ้นที่แรงที่สุดของหน้า ทำให้ราคาที่แพงกว่าเข้าใจได้
4. **ตัวเลข proof ไม่มีของปลอมเลย** — ทุกตัวสืบกลับ `company.md` ได้
5. **แต่ละ section หน้าตาไม่ซ้ำกัน** — bento / steps / ตาราง / accordion / รูปเต็มกว้าง สลับกันไป

## Quick wins ที่ทำไปแล้ว

- ✅ `scroll-margin-top:90px` ทุก anchor — กด CTA แล้วหัวข้อฟอร์มไม่โดน nav บัง (ยืนยันด้วยภาพ)
- ✅ H1 เหลือ 2 บรรทัดสะอาด (ลด 56→52px · คอลัมน์ซ้ายกว้างขึ้น · ล็อกวลีที่ 2 ไม่ให้ขาด) — มือถือปล่อยตัดตามปกติ
- ✅ placeholder อีเมลในฟอร์ม hero สั้นลง ไม่โดนตัด

## ที่เหลือและเหตุผลที่ยังไม่ทำ

| เรื่อง | ทำไมยังไม่ทำ |
|---|---|
| ใส่ testimonial | **ไม่มีของจริง** — แต่งขึ้นผิดกฎโปรเจกต์และผิดจรรยาบรรณ ต้องรอเคสจริงจากเปา |
| ใส่กรอบเวลาออกใบเสนอราคา | เปายังไม่ยืนยันตัวเลข — ใส่ไปแล้วกลายเป็นคำสัญญาที่อาจทำไม่ได้ |
| ใส่ urgency | ไม่มีโปรจริงตาม brief — countdown ปลอมผิดกฎหมายคุ้มครองผู้บริโภค |
| ปุ่ม CTA ลอยติดขอบล่างบนมือถือ | หน้าอยู่ที่ ~11,300px บนมือถือ น่าจะช่วยได้ แต่เป็นการเพิ่ม element ที่ควรตัดสินใจร่วมกับเปาก่อน |
| GA4 / Meta Pixel | `config.js` เว้น id ว่างไว้ — ยังไม่มี property/pixel ของ CMH |

- [x] มี texture (noise 2.8%) + depth จากรูป overlay
- [x] hero หยุดสายตาได้ (ลานตู้มุมสูงเต็มจอ)
